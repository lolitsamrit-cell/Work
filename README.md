# Code Reviewer App

A lightweight browser-based app for quick code reviews.

## Features
- Paste code and choose a language.
- Run automated checks for common quality issues.
- View categorized findings by severity.
- See a summary score and improvement hints.

## Run locally
Open `/home/runner/work/Work/Work/index.html` in your browser.

## Checks included
- Long lines
- TODO/FIXME markers
- `console.log`/`print` debug traces
- `==` usage warning
- Missing semicolon hints (JavaScript)
- Broad `except:` warning (Python)
- Deep nesting warning
